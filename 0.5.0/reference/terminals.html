Terminals ​

Terminal operations.

Use it as client.terminals. Every method takes keyword arguments, returns a PaystackSdk::Response, and raises a PaystackSdk::Error if a parameter is invalid before anything is sent. An unsuccessful result from Paystack (a 400 or 404) comes back as a Response with success? false.

Methods ​

send_event ​

ruby
terminals.send_event(terminal_id:, type: nil, action: nil, data: nil)

Send Event.

Send an event from your application to the Paystack Terminal

ParameterTypeRequiredDescription
terminal_idStringyesThe ID of the Terminal the event should be sent to.
typeStringThe type of event to push One of: invoice, transaction.
actionStringThe action the Terminal needs to perform. One of: process, view, print.
dataHashThe parameters needed to perform the specified action

Note

This pushes the event to a physical Paystack Terminal. Not verified against the Paystack API: the test account used to build this SDK has no Terminal access.

Paystack docs: https://paystack.com/docs/api/terminal/#send-event
