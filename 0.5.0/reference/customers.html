Customers ​

Customer operations.

Use it as client.customers. Every method takes keyword arguments, returns a PaystackSdk::Response, and raises a PaystackSdk::Error if a parameter is invalid before anything is sent. An unsuccessful result from Paystack (a 400 or 404) comes back as a Response with success? false.

List Customers.

List customers on your integration

ParameterTypeRequiredDescription

per_pageIntegerThe number of records to fetch per request
