Disputes ​

Dispute operations.

Use it as client.disputes. Every method takes keyword arguments, returns a PaystackSdk::Response, and raises a PaystackSdk::Error if a parameter is invalid before anything is sent. An unsuccessful result from Paystack (a 400 or 404) comes back as a Response with success? false.

Methods ​

list ​

ruby
disputes.list(per_page: nil, page: nil, status: nil, transaction: nil, from: nil, to: nil)

List Disputes.

List transaction disputes filed by customers

ParameterTypeRequiredDescription
per_pageIntegerNumber of records to fetch per page
pageIntegerThe section to retrieve
statusStringDispute status One of: awaiting-merchant-feedback, awaiting-bank-feedback, pending, resolved.
transactionStringTransaction ID
fromStringThe start date
toStringThe end date

Paystack docs: https://paystack.com/docs/api/dispute/#list
