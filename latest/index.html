Mirrors Paystack

Every endpoint follows Paystack's documentation, checked in CI against its OpenAPI spec. Where the docs and the spec disagree, the live test API settles it.

Safe with money

Amounts are integers in the smallest unit, paid? checks amount and currency, writes are never retried after a timeout, and the secret key never shows in inspect output.
