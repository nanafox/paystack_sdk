How a payment works
API reference
payments_controller.rb
client = PaystackSdk::Client.new

# 1. start the payment, send the payer to Paystack
res = client.transactions.initiate(
  email: "ama@example.com", amount: 5000,
  currency: "GHS", reference: "pay-8f2c"
)
redirect_to res.authorization_url

# 2. on the callback or webhook: ask Paystack, not the browser
res = client.transactions.verify(reference: "pay-8f2c")
grant_access if res.paid?(amount: 5000, currency: "GHS")

Follows Paystack's docs

Each endpoint is checked in CI against Paystack's OpenAPI spec. Where the docs and the spec disagree, the live test API decides.

Careful with money

Amounts are integers in the smallest unit. paid? checks amount and currency. A write is never retried after a timeout, and the secret key stays out of inspect output.

Results you can read

success? means Paystack accepted the call, not that a charge worked. The status and the amount are checked separately, and the docs say which is which.
