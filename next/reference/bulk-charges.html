Bulk Charges ​

Bulk Charge operations.

Use it as client.bulk_charges. Every method takes keyword arguments, returns a PaystackSdk::Response, and raises a PaystackSdk::Error if a parameter is invalid before anything is sent. An unsuccessful result from Paystack (a 400 or 404) comes back as a Response with success? false.

Methods ​

list_batches ​

ruby
bulk_charges.list_batches(per_page: nil, page: nil, status: nil)

List Bulk Charge Batches.

List all bulk charge batches.

ParameterTypeRequiredDescription
per_pageIntegerNumber of records to fetch per page
pageIntegerThe offset to retrieve data from
statusStringFilter by the status of the charges One of: active, paused, complete.

Paystack docs: https://paystack.com/docs/api/bulk-charge/#list
